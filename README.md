# generaptr

Generate a REST API boilerplate or an API spec from a database schema.

| Package | Path | npm |
|---|---|---|
| Core library | [`packages/core`](packages/core) | `generaptr` |
| CLI | [`packages/cli`](packages/cli) | `generaptr-cli` |

```sh
pnpm install
pnpm build
pnpm test   # needs MySQL with packages/core/test/handlers/mysql/data.sql loaded
```

See [PLAN.md](PLAN.md) for the modernization plan.
